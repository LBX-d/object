# 阶段小结 1：建立 prompt 自动备份机制

**日期**：2026-08-27

## 这个阶段做了什么

1. 在 `新建文件夹` 下创建了 `prompt` 目录，用于保存与 AI 的全部对话记录
2. 把已有的 3 个历史会话记录（jsonl 文件）复制了进去
3. 配置了 Claude Code 的**自动备份钩子**（配置在 `C:\Users\asus\.claude\settings.json`）：
   - **PreCompact 钩子**：每次上下文压缩发生前，自动把当时的完整对话存一份带时间戳的快照
   - **SessionEnd 钩子**：每次会话结束时，自动更新最新完整记录
4. 备份脚本保存在 `C:\Users\asus\.claude\backup_zuoye_prompt.py`（已测试通过）

## 目录结构

```
prompt/
├── README.md                    ← 本目录的说明
├── transcripts/                 ← 每个会话的最新完整记录（.jsonl）
│   └── 压缩前快照/              ← 上下文压缩前的历史快照（文件名带时间戳）
└── 阶段记录/                    ← 每个工作阶段的人工小结（本文件所在位置）
```

## 工作原理（通俗版）

- 对话记录的"本体"由 Claude Code 自动保存在 `C:\Users\asus\.claude\projects\` 里
- 配置的钩子会在两个关键时刻自动把记录复制到本目录：
  1. **上下文压缩前** → 存快照，保证压缩前的完整对话不丢失
  2. **会话结束时** → 更新最新版
- 备份只针对 Desktop\zuoye 下的会话（按路径中是否含 "zuoye" 判断），其他项目不受影响

## 后续约定

- 每个工作阶段结束后，Claude 会在 `阶段记录/` 写一份新的小结，并同步最新的 jsonl 记录
- 压缩前、会话结束的备份由钩子**全自动**完成，无需人工干预
